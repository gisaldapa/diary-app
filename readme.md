# Diary App - Mobile Programming

Aplikasi Buku Harian (Diary App) sederhana yang dikembangkan menggunakan **React Native** dengan **Expo CLI** sebagai bagian dari tugas Mobile Multi PLatform Kelas .

## Fitur & Tugas yang Diselesaikan
- **Struktur Komponen & Folder:** Menggunakan pemisahan folder `src/screens` dan `src/components`[cite: 2, 6].
- **Komponen Reusable:** Komponen `DiaryCard` dipisah dan digunakan kembali menggunakan *props*[cite: 13, 16].
- **Daftar Entri (5+ Data):** Menampilkan minimal lima entri buku harian secara dinamis menggunakan metode `map()`[cite: 9, 19].
- **Media Gambar:** Menggunakan kombinasi gambar *remote* (URL) dan gambar lokal dari folder `assets/moods/`[cite: 16, 17, 19].
- **Header dengan Avatar:** Menambahkan foto avatar pengguna di bagian atas header aplikasi[cite: 19].
- **Border Dinamis:** Variasi warna pinggiran kartu (border) secara otomatis menyesuaikan berdasarkan jenis *mood*[cite: 19].
- **Safe Area:** Tampilan aman dari *notch* menggunakan `react-native-safe-area-context`[cite: 4, 12].
